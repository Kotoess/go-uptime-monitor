# Go Uptime Monitor

Небольшой CLI-инструмент на Go для периодической проверки доступности одного HTTP-сервиса.

Программа выполняет `GET`-запрос к указанному URL, измеряет время ответа и выводит состояние:

- `UP` — сервер ответил HTTP-кодом из диапазона `200–299`;
- `DOWN` — произошла сетевая ошибка, таймаут или сервер вернул другой HTTP-код.

## Возможности

- проверка одного URL по заданному интервалу;
- настройка таймаута HTTP-запроса;
- измерение времени ответа;
- различение сетевой ошибки и неуспешного HTTP-статуса;
- тесты для `200 OK` и `503 Service Unavailable` через локальный `httptest`-сервер.

## Требования

- Go `1.27.3` или совместимая версия.

## Запуск

Проверять URL каждые 2 секунды с таймаутом 10 секунд:

```bash
go run . https://example.com
```

Задать свой интервал и таймаут:

```bash
go run . -interval 5s -timeout 3s https://example.com
```

Остановить мониторинг можно через `Ctrl+C`.

## Аргументы

| Флаг | По умолчанию | Описание |
|---|---:|---|
| `-interval` | `2s` | Интервал между HTTP-проверками. |
| `-timeout` | `10s` | Максимальное время выполнения одного HTTP-запроса. |

Справка:

```bash
go run . -h
```

## Пример вывода

```text
2026-11-12T14:30:00Z UP 200 145ms https://example.com
2026-11-12T14:30:05Z DOWN 503 98ms https://example.com
```
